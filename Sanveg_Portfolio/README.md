## 🚀 How to Deploy on Netlify

### Option 1: Netlify Drop (Instant Drag-and-Drop)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Open File Explorer to:
   `c:\Users\Sahil Sabale\OneDrive\Desktop\Projects\Portfolio\Sanveg_Portfolio`
3. Drag and drop the `Sanveg_Portfolio` folder directly onto the upload box.
4. Your website is instantly live!

### Option 2: Netlify CLI
Run the following inside `Sanveg_Portfolio`:
```bash
npx netlify deploy --prod
```
